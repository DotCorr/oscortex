  CANONICAL UI RUNTIME
  ────────────────────
  Flutter is the PERMANENT OS UI runtime. Every pixel on screen is rendered by
  the Flutter engine. Other engines (Rive, Unity, Unreal, custom C++/Skia) are
  integrated EXCLUSIVELY as Flutter-hosted views/textures via platform-channel
  FFI — never as parallel render paths, never as alternative shells.
  The OS owns the asset/loader ABI; engines plug into it.
